# 布控告警误报分析规范

## 适用场景

人员聚集、越界、徘徊、区域入侵、离岗等告警出现频繁误报时，需要结合现场截图、告警时间线和规则配置进行分析。

## 常见误报原因

- 玻璃、地面或金属反光导致目标检测异常。
- 摄像头角度变化导致布控区域偏移。
- 夜间补光、雨雪、树影或广告屏闪烁造成干扰。
- 阈值过低，过滤条件缺失。

## 处置建议

1. 查看告警前后截图和短视频。
2. 检查布控区域、阈值、过滤条件和生效时间段。
3. 对误报样本进行标注，沉淀为长期案例。
4. 调整规则或停用告警前需要人工审核。
