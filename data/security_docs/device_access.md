# 摄像头接入与离线排查手册

## 设备离线现象

摄像头接入平台后可能出现心跳丢失、视频流不可用、GB28181 注册失败、RTSP 拉流超时等问题。

## 排查步骤

1. 检查设备供电、网线、交换机端口和 VLAN。
2. 检查 IP、网关、DNS、NTP 时间和平台接入参数。
3. 检查 GB28181 设备 ID、SIP 域、用户名和密码。
4. 检查 RTSP 地址、鉴权信息和流媒体服务日志。
5. 如果需要重启设备或修改平台配置，需要人工确认。
