# 私有化部署排障指南

## 常见问题

私有化部署后可能出现接口异常、服务启动失败、知识库检索为空、模型服务不可用、Milvus 或 Redis 连接失败等问题。

## 排查步骤

1. 检查 `.env`、服务端口、模型服务地址和 API Key。
2. 检查 SQLite、日志目录、索引目录是否具备写权限。
3. 检查 OCR、embedding、检索服务是否启动。
4. 检查 `/health`、`/ingest`、`/query` 接口。
5. 对低置信度回答进入人工审核。

## 生产增强

轻量版本使用 SQLite 保存索引，生产环境可以替换为 Milvus Dense / Sparse 双索引和 Redis 短期记忆。
